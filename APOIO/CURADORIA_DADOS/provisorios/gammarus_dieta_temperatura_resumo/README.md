# Gammarus — dieta e temperatura (resumo)

Tabela agregada no nível da combinação dieta × temperatura para juvenis de
*Gammarus locusta*. São 12 linhas, com médias, desvios-padrão e `n = 4` por
combinação; não são os 48 valores de cada recipiente.

- Fonte: Ribes-Navarro et al. (2022), *Frontiers in Marine Science*, 9, 931991,
  DOI [10.3389/fmars.2022.931991](https://doi.org/10.3389/fmars.2022.931991).
- Licença: CC BY.
- Uso: EAPADados, gráficos, discussão do delineamento e interpretação dos
  resultados reportados pelos autores.
- Restrição: não recalcular ANOVA, pressupostos ou pós-testes com este arquivo;
  para isso são necessários os valores de cada recipiente.

A tabela foi transcrita da Table 1 do artigo. A advertência sobre a natureza
agregada está repetida no dicionário do pacote e na atividade correspondente.
