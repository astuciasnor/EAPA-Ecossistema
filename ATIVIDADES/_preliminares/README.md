# Atividades preliminares

Esta pasta reúne rascunhos de atividades desmembrados de abas internas ainda não
incorporadas ao `EAPADados`. Os enunciados e planilhas foram preservados para
triagem, mas não são atividades consolidadas nem material pronto para
distribuição pública.

Antes de promover qualquer item para `atividades/`, é preciso confirmar a fonte,
a licença/autorização, a unidade observacional, a rubrica e a coerência do
arquivo Excel. Os arquivos `.inspect.ndjson` são apenas relatórios auxiliares
de inspeção das planilhas.
